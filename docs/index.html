Open the report on your PC

  1. Download the ZIP and choose Extract All. Keep the extracted folders together. Do not open the project inside the ZIP.
  2. Close any previously opened copy of the report. In the extracted folder, review and run Setup-DataPaths.ps1 with PowerShell. It points the model to that folder's included data files.
  3. Open RedAndYellow.pbip in a current Power BI Desktop version with project support, then select Refresh.
  4. If you move the extracted folder, run the setup script again before reopening the report.

The source repository excludes the large data files; use the release ZIP for the complete portable package. The original project filenames are retained so report references continue to work.

How to interpret the evidence

This is a portfolio case study. Analytical people, spend and student outcomes are synthetic or illustrative, not an institution's actual results. The ebook distinguishes the live Salesforce demo extract from staged custom-object data and the larger analytical population. Predictive scores support human review; they are not validated production outcomes. Fabric and Google Cloud implementation status and remaining limitations are documented in the ebook.
